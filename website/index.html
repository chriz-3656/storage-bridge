The Universal Cloud Filesystem

A blazing-fast, AI-native CLI and Daemon that unites S3, Google Drive, Local, and more into a single seamless architecture.

Union Load Balancing

Merge multiple cloud providers into a single virtual pool. Dynamically route uploads via 'first' available or 'all' mirroring policies.

Parallel Sync Engine

High-performance, concurrent differential sync. Builds an in-memory diff map and transfers only modified files using GoRoutines.

AI-Native MCP Server

Built-in JSON-RPC server implementing the Model Context Protocol. Empower LLM agents to natively manage your files without complex APIs.

Universal Compatibility

Native connectors for Google Drive, Local FS, Amazon S3, Cloudflare R2, Backblaze B2, and DigitalOcean Spaces via custom endpoints.

Quick Start

Download the pre-compiled binary from GitHub Releases and add it to your path.

# Download and install
curl -L -o storage-bridge https://github.com/chriz-3656/storage-bridge/releases/latest/download/storage-bridge-linux-amd64
chmod +x storage-bridge
sudo mv storage-bridge /usr/local/bin/

# Authenticate with a cloud provider
storage-bridge auth login google

# Add a new Cloudflare R2 bucket
storage-bridge provider add my-r2 --type s3 --bucket images --endpoint https://<id>.r2.cloudflarestorage.com

# Set as your default provider
storage-bridge default set my-r2

Core Commands

Storage Bridge offers a stateful CLI. You can cd into a cloud directory just like a local filesystem.

# Navigate your cloud natively
storage-bridge cd /my-backups/2024
storage-bridge pwd

# List, Create, and Move
storage-bridge mkdir new-folder
storage-bridge list
storage-bridge move old.txt new-folder/new.txt

# High-Speed Syncing (Differential)
storage-bridge sync local:/home/user/data my-r2:/cloud-backup --workers 8

Union Load Balancing

Combine multiple storage providers into a single virtual pool. The routing engine handles the heavy lifting.

# Combine a local drive and an S3 bucket
storage-bridge provider add hybrid-cloud --type union --upstreams local,my-r2 --policy first

# Uploading to the union automatically routes the file
storage-bridge upload massive-file.mp4 hybrid-cloud:/media

Model Context Protocol (MCP)

Expose your configured storage providers directly to AI assistants like Claude or Antigravity via JSON-RPC.

# Start the MCP daemon over STDIO
storage-bridge mcp

# The server exposes the following tools:
# - read_file
# - write_file
# - list_directory
# - make_directory
# - move_file
